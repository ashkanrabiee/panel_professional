# 🛒 Ecommerce Project

This project is a sophisticated and feature-rich **ecommerce platform** built using **Laravel**. It offers an advanced admin panel, a variety of user management options, and tools to manage products, discounts, orders, and inventory. It also includes integrations for SMS and email notifications, OTP-based authentication, and a dedicated image upload service.

## 🚀 Features

- **Slug**: URL slugs to enhance SEO.
- **Intervention Image**: Image handling and manipulation library.
- **Softdelete**: Ability to soft delete records.
- **Jalalidate**: Persian calendar validation and handling.
- **Sweetalert & Toast**: For rich notifications and alerts in the user interface.
- **Custom Image Upload Service**: Dedicated service for handling image uploads.
- **OTP Authentication**: Secure One-Time Password (OTP) for user authentication.
- **Email and File Sending**: Email notifications and file attachment capabilities.
- **Admin Panel**: A powerful admin panel to manage all aspects of the store.
    - **Product Management**: Add, update, and delete products.
    - **Discount Management**: Manage promotional discounts for customers.
    - **Order and Inventory System**: Track orders, manage inventory.
    - **Roles & Permissions**: Manage roles for users and assign permissions.
    - **Banner Management**: Manage banners displayed on the site.
    - **SMS and Email Notifications**: Notify customers with promotional or transactional messages.
